# Avisos de terceros

Lienzo usa estos proyectos de código abierto. Cada uno conserva su licencia.

| Proyecto | Licencia | Para qué |
|---|---|---|
| [Tauri](https://tauri.app) y sus plugins `dialog`, `fs` y `updater` | MIT o Apache-2.0 | Aplicación de escritorio y Android, actualizaciones |
| [reqwest](https://github.com/seanmonstar/reqwest), [rustls](https://github.com/rustls/rustls), [webpki-roots](https://github.com/rustls/webpki-roots), [minisign-verify](https://github.com/jedisct1/rust-minisign-verify) | MIT / Apache-2.0 / ISC / MPL-2.0 | Descargar y verificar actualizaciones en Android |
| [sql.js](https://github.com/sql-js/sql.js) | MIT | Leer y escribir la base de datos de los archivos `.clip` |
| [ag-psd](https://github.com/Agamnentzar/ag-psd) | MIT | Leer y escribir PSD |
| [Vite](https://vitejs.dev), [TypeScript](https://www.typescriptlang.org), [Vitest](https://vitest.dev) | MIT / Apache-2.0 | Herramientas de desarrollo |

La lista completa de dependencias, con sus licencias, sale de `npm ls` y de `cargo tree` (por ejemplo con `cargo license`).
